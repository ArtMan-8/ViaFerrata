# Правила для агентов

Этот репозиторий публичный и самодостаточный: каждый файл должен быть понятен без внешних закрытых источников.

- Не ссылайся на личные заметки и документы вне репозитория. Нужен факт — приведи публичный первоисточник и дату проверки.
- Документы пишем по-русски; заголовки разделов — канонические английские. Идентификаторы, код и сообщения коммитов — по-английски.
- Ветки — `<вид>/<тема>`; виды: `docs`, `adr`, `research`, `spec`, `impl`. Тема — слаг в kebab-case; подчёркивание отделяет идентификатор от темы. Подробности — ADR-0001.
- Коммиты — Conventional Commits, только индекс (`git commit` без `-a`).
- Агент не коммитит, не пушит и не сливает, пока это не разрешено явно.
