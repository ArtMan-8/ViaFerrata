# Работа в ViaFerrata

Прочитай README, `instructions/workflow.md` и комплект текущего change. Комплект `change-000002` описывает реализованное подключение проекта командой init; Plan завершён. Основание принятия и актуальные результаты — в Journal. Исторический `change-000001` завершён в пределах первого CLI; повторного согласования его неизменной части не требуется.

Перед изменениями проверь состояние репозитория Git и существующие пользовательские изменения. Сохраняй чужую работу. Пиши содержание документов по-русски; стандартные заголовки, поля и ID сохраняй по шаблонам.

Коммиты оформляй по Conventional Commits на английском. Заголовок — одно предложение о том, что сделал. Если его недостаточно, добавь тело из 2–3 предложений о выполненных изменениях; иначе тело опусти. Рабочая ветка change-000002 — `feat/project-init`; при продолжении сверяй её с Git.

Plan — единственный checklist задачи. Journal создаётся с началом Implement; в нём сохраняются основание согласования, точка продолжения и фактические результаты. Не создавай пустые SRS, ADR, Research и дополнительные task/handoff-файлы ради формы.

Действующие общие правила: `instructions/workflow.md`; формы и матрица отношений: `templates/README.md`. Текущий контракт: `viaferrata/changes/change-000002/spec.md`; действующий контракт первого CLI: `viaferrata/changes/change-000001/spec.md`. Новые обязательства и расширение scope согласуются как изменения к принятому контракту; технические детали внутри принятого контракта решает исполнитель. Работа ограничена текущим репозиторием.

Обязательные проверки: `npm ci`, `npm run typecheck`, `npm test`, `npm run build`, `node bin/vf.ts --root . validate`, `git diff --check` и сверка tracked/untracked со scope. Тесты CLI работают в `/tmp/vf-test-*`, установка tarball также изолирована от рабочей директории. Временные каталоги тестов CLI и установки tarball очищаются после соответствующих тестов. Отсутствующая проверка не считается пройденной. `validate` не подтверждает человеческое согласование, смысловую полноту или завершённость.

Публикация и выпуск требуют отдельного поручения. Субагенты не обязательны; отдельного агентного runtime и командной координации не строим.

Навигация по разработке: [Intent init](viaferrata/changes/change-000002/intent.md), [текущий Plan](viaferrata/changes/change-000002/plan.md), [текущий Journal](viaferrata/changes/change-000002/journal.md), [результаты первого CLI](viaferrata/changes/change-000001/journal.md), [независимые фикстуры](tests/fixtures/validation/README.md), [глоссарий проекта](docs/GLOSSARY.md). При работе с терминологией сверяй определения с глоссарием и действующими источниками правил.

Перед итоговыми проверками завершай форматирование и автоисправления. Необязательная команда `node scripts/input-manifest.ts` выводит пофайловые SHA-256 и общий отпечаток для диагностики или передачи снимка. Постоянный манифест не требуется. Временные данные храни в игнорируемой `.viaferrata/`, команды, среду, фактические результаты и ограничения — в Journal. После изменения входов выполни затронутые проверки; результаты относятся только к проверенным входам. Комплект текущей задачи описывает конечное состояние без хронологии правок; Journal сохраняет краткое основание согласования и актуальный итог.
