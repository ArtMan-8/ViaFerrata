# Полное причёсывание кода и подключение инженерных проверок

## Technical Approach

Принятая 2026-11-14 дельта включена в Intent и Spec. Основание — Journal: Agreed Delta и Discussion Evidence; повторное согласование не требуется. Ветка — chore/code-quality. Сохраняются пользовательские staged/unstaged-изменения и index. Подготовка продолжения начата; execution: in_progress отражает незавершённый объём дельты. P-1–P-8 относятся к первоначальной реализации и не подтверждают новые обязательства.

Парсер использует node:util parseArgs, проверяет повторы по токенам и принадлежность опций команде; cwd передаётся с границы CLI. Выбор проекта выполняется отдельно от разбора аргументов по R-6. IndexProject выделяется из documents/index.ts в именованный модуль сценария; построение индекса и проверка комплектов остаются вместе. Union состояния документа исключает body при metadata=null, а поля YAML остаются unknown до проверки. Сохраняются cli/commands/documents и корневые config.ts, filesystem.ts, resources.ts, diagnostics.ts.

Ожидаемые ошибки преобразуются на соответствующих границах; непредвиденные дефекты достигают границы CLI как E_INTERNAL со стеком. InitIO/ChangeIO и узкий lstat-интерфейс сохраняются. Проверки сочетаний write/close/cleanup предшествуют исправлениям потери причин. Политики init/new не объединяются; общие помощники вводятся только для реального повторения.

Тесты поведения модулей размещаются рядом с ними, общие сценарии, помощники и независимые фикстуры — в src/tests. Npm test остаётся без сетевой установки; test:package проверяет полный сценарий поставки, test:all запускает оба набора последовательно. Typecheck включает тесты, сборка и tarball исключают тесты, помощники и фикстуры. Отдельное разрешение на удаление старых путей при переносе получено и исполнено; установки devDependencies, npm ci, установка tarball и очистка node_modules, dist и временных каталогов уже разрешены для текущего change.

Согласованные конфигурации — oxlint.config.mts, oxfmt.config.mts и .markdownlint-cli2.mjs. Oxfmt использует группы [type-builtin, value-builtin], [type-external, value-external], [type-internal, value-internal, type-subpath, value-subpath], [type-parent, value-parent, type-sibling, value-sibling, type-index, value-index], затем unknown; newlinesBetween=true. Ширина — 100, proseWrap=preserve, sortSideEffects=false; остальные оговорённые значения по умолчанию не дублируются. Сортировка package.json/scripts и механическое форматирование истории включены. Семь шаблонов сначала проверяются на копиях. Содержимое независимых фикстур при переносе сохраняется.

Обновление markdownlint-cli2 с 0.22.1 до 0.24.1 выполняется через npm с проверкой совместимости и audit; @types/node остаётся в основной версии 24. High/critical требуют устранения либо принятия конкретного риска. Таймаут запроса установки — 60 секунд, один повтор с задержкой 1–5 секунд, установка — 180 секунд, тест поставки — 240 секунд. Пустой кеш, недоступность источника и перенос установки сохраняются.
