# Контроль diff и согласованного scope

## Goal

Агент проверяет фактические пути изменения относительно области, которую пользователь принял для deep-задачи. После перерыва для проверки достаточно репозитория и Journal.

## Constraints

Проверка доступна при незакоммиченной Spec и наличии посторонних изменений в рабочем дереве. Полный список разрешённых путей хранится в Spec. Ограничения доступа к файлам обеспечивает среда. Для vibe комплект создавать не требуется.

## Context

До введения команды агент сверял пути Git со Spec вручную. В change-000008 модуль summary и его тест охватывала одна маска, в change-000009 те же пути перечислили отдельно. Эти примеры позволяют проверить правило выбора масок.
