# Подготовка и первая публикация ViaFerrata 0.1.0

## Goal

Подготовить и опубликовать первый ограниченный выпуск `viaferrata@0.1.0`: пользователь подключает проект через npx или глобально установленный vf, работает с агентом по понятным инструкциям и получает проверяемые документы. Перед публикацией получить проверенный tarball, описание возможностей и ограничений, CHANGELOG и воспроизводимый порядок выпуска.

## Constraints

Сохраняются init/new/validate, форматы документов и Node.js 24.x. Runner, автоматические approval/evidence, контроль scope/diff/finish, полная поддержка strict, отдельные skills и вызов LLM из CLI не входят в задачу. Не обещать неподтверждённую поддержку ОС. Не вводить обязательный повтор полного пилота второго проекта или дополнительные документы на каждую задачу потребителя.

Выпуски публикуются вручную локально из проверенного архива сохранённой ревизии trunk. Коммит, push, merge и отправка пакета требуют отдельных поручений. Перед отправкой пользователь принимает конкретный кандидат и результаты его проверок. После проверки registry создаются Git-тег v0.1.0 и GitHub Release с описанием из CHANGELOG. Для входа в npm используется интерактивная авторизация пользователя с 2FA.

Обычный выпуск, включая подготовку CHANGELOG в отдельной ветке, не требует отдельного change-комплекта, Journal или служебного коммита с результатами. Текущий комплект описывает разработку процесса и первую публикацию.

## Context

Init/new/validate и независимая установка tarball уже реализованы. Предыдущая задача завершена. Её результаты сохранены в [Journal change-000003](../change-000003/journal.md). Пересмотр её обязательств в этот выпуск не входит. Новый кандидат проходит собственные проверки перед выпуском.

Испытание процесса во втором проекте подтверждено в обсуждении; отдельный транскрипт не восстановлен. Доступная история собственного применения содержит случаи повреждения placeholder при форматировании, неполных условий проверки поставки и конфликта повторного init после форматирования. Неизвестные подробности второго проекта не реконструируются вымыслом.

Согласованы viaferrata@0.1.0 с тегом latest, запуск через npx и глобальный vf, краткий README и подробный quickstart. Агент готовит CHANGELOG по данным Git, diff и контрактам; отдельный LLM API не нужен. Основания согласования и результаты выполненных работ сохранены в Journal.
