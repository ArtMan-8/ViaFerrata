# Покрытие требований шагами Plan

## Goal

Обнаруживать требование без запланированного шага средствами ViaFerrata. Проект выбирает профиль и при необходимости включает дополнительное встроенное правило.

По ID из сообщения CLI пользователь находит в каталоге нарушенное условие, область его применения и профиль. Если в волне Plan или при архивировании комплекта нарушены оба независимых условия, CLI сообщает о каждом за один запуск.

## Constraints

Core обязателен в обоих профилях. Команды продукта запускает агент или существующий CI. Сведения о фактическом результате и проверенной редакции остаются в Journal deep-задачи.

## Context

Исходный CLI индексирует ID и ссылки. Само существование адресата ещё позволяет оставить требование без шага реализации.
