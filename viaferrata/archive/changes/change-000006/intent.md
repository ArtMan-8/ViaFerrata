# Покрытие требований шагами Plan

## Goal

Выявлять требования, для которых в Plan нет шага реализации. Проект выбирает профиль и при необходимости включает дополнительное встроенное правило.

По ID из сообщения CLI пользователь находит в каталоге нарушенное условие, область его применения и профиль. Если в волне Plan или при архивировании комплекта нарушены оба независимых условия, CLI сообщает о каждом за один запуск.

## Constraints

В обоих профилях обязательны базовые проверки (core). Команды продукта запускает агент или существующий CI. Сведения о фактическом результате и проверенной редакции остаются в Journal deep-задачи.

## Context

До этого изменения CLI индексировал ID и проверял ссылки. Требование могло иметь корректный адрес, даже если ни один шаг Plan его не покрывал.
