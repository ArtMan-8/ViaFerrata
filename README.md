# ViaFerrata

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

ViaFerrata — инструкции, шаблоны документов и CLI для разработки с AI-агентом. Помогает связать цель задачи с требованиями, реализацией и проверками, а также продолжать работу между сессиями. Рассчитана на одного разработчика: человек согласует задачу, агент ведёт документы и выполняет работу, CLI проверяет их структуру.

## Возможности

- `vf init [path] --profile lite|strict` — подключает существующий каталог проекта: создаёт конфигурацию, добавляет навигацию в AGENTS.md и исключение временных данных в .gitignore.
- `vf new "Название задачи"` — создаёт Intent, Spec и Plan: цель, требования и план работы.
- `vf validate` — проверяет метаданные, ID, обязательные разделы и ссылки документов.
- Шаблоны Journal, SRS, Research и ADR — для результатов работы, требований системы, исследований и архитектурных решений по необходимости.

Документы хранятся в проекте. Агент заполняет созданные черновики; обновление пакета их не перезаписывает.

## Быстрый старт

Требуются Node.js 24.x и npm. Пакет пока не опубликован; запуск из каталога исходников:

```sh
npm ci
node bin/vf.ts --help
node bin/vf.ts init /path/to/project --profile lite
cd /path/to/project
node /path/to/ViaFerrata/bin/vf.ts new "Название задачи"
node /path/to/ViaFerrata/bin/vf.ts validate
```

Замените пути на свои. `new` и `validate` находят ближайший `viaferrata.toml` вверх от рабочего каталога. После `new` заполните документы: незаполненные черновики не проходят проверку.

Повторный `init` сохраняет готовое подключение; при существующей конфигурации `--profile` можно опустить. При конфликте с изменённым блоком ViaFerrata в AGENTS.md сохраните ручные дополнения вне блока и разрешите конфликт перед повтором. При ошибке записи исправьте указанную причину и повторите команду: готовые части сохранятся.

## Ограничения

CLI выполняет базовые структурные проверки. Полный контроль профилей `lite` и `strict`, покрытия требований, границ изменений и завершения задачи пока не реализован. Успешный `validate` не подтверждает согласование, смысловую полноту или качество реализации.

## Разработка

```sh
npm run lint
npm run format:check
npm run typecheck
npm run test:all
npm run build
```

`npm test` запускает локальные тесты; `npm run test:package` проверяет установку и работу пакета и требует доступа к npm registry. `npm run test:all` выполняет оба набора. `npm pack` собирает JavaScript и создаёт архив для локальной установки.
