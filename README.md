# ViaFerrata

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**ViaFerrata** — инструкции, шаблоны документов и CLI для разработки с AI-агентом. Помогает превращать намерение человека в проверяемое изменение, поддерживать согласованность требований и кода и продолжать работу между сессиями без восстановления всей переписки.

Текущий фокус — один разработчик. Человек задаёт цель и принимает существенные решения; агент готовит документы, реализует изменение и проверяет результат. CLI автоматизирует формальные операции и структурные проверки документов.

## Подход

- **От цели к проверке.** Ожидаемое поведение и ограничения направляют реализацию; результат проверяется относительно задачи.
- **Минимум ручной работы.** Документы ведёт агент, формальные операции выполняют инструменты. Дополнительные артефакты создаются по необходимости.
- **Актуальные требования рядом с кодом.** Принятые изменения отражаются в требованиях, реализации и проверках в рамках одной работы.
- **Контекст для продолжения.** План и журнал сохраняют ход работы, существенные решения и фактические результаты.

Глубина оформления задачи и строгость проверок — независимые настройки:

| Ось           | Назначение                                                                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vibe/deep`   | Формализация задачи: vibe не требует отдельных task-документов; deep использует Intent, Spec и Plan, а при исполнении — Journal.                         |
| `lite/strict` | Профиль обязательного автоматического контроля проекта. Strict предполагает дополнительные применимые проверки, а не дополнительные ручные согласования. |

В обоих режимах действуют требования и правила проекта. Текущий CLI реализует только часть этой модели; ограничения перечислены ниже.

## Возможности

- `vf init [path] --profile lite|strict` — подключает существующий каталог проекта: создаёт конфигурацию, добавляет навигацию в AGENTS.md и исключение временных данных в .gitignore.
- `vf new "Название задачи"` — создаёт черновики Intent, Spec и Plan для deep-задачи: цель, требования и план работы.
- `vf validate` — проверяет целостность рабочих и архивных документов, дельты и ссылки; сообщает о несоответствии текущей форме и незавершённой синхронизации.
- Шаблоны Journal, SRS, Research и ADR — для результатов работы, действующих требований системы, исследований и архитектурных решений по необходимости.

Документы принадлежат проекту. Агент заполняет и актуализирует их; обновление пакета их не перезаписывает.

## Быстрый старт

Требуются Node.js 24.x и npm.

Выберите один способ запуска.

Через npx:

```sh
npx viaferrata@0.1.0 --help
npx viaferrata@0.1.0 init /path/to/project --profile lite
```

Через глобально установленный vf:

```sh
npm install -g viaferrata@0.1.0
vf --help
vf init /path/to/project --profile lite
```

После init откройте проект с агентом и назовите выбранный способ запуска. Для deep-задачи агент вызывает `new`, заполняет Intent/Spec/Plan и согласует их с вами перед реализацией; при её начале ведёт Journal. Для vibe-задачи команда new не требуется. В новой сессии агент повторяет help выбранным способом и находит текущие инструкции.

[Подробное руководство](https://github.com/ArtMan-8/ViaFerrata/blob/trunk/docs/quickstart.md) описывает полный путь до validate, повтор init и продолжение работы.

## Ограничения

CLI выполняет базовые структурные проверки. Для рабочих deep-комплектов strict дополнительно проверяет покрытие требований Spec шагами Plan. В lite эту же проверку включает `required_checks = ["plan-requirement-coverage"]`. Полный контроль профилей `lite` и `strict`, покрытия требований, границ изменений и завершения задачи пока не реализован. Выбор `strict` не означает, что весь предусмотренный профиль уже автоматически обеспечивается.

Успешный `validate` не подтверждает человеческое согласование, смысловую полноту требований или качество реализации. Проверки кода и поведения выполняются средствами проекта; фактические результаты и ограничения агент фиксирует в Journal для deep-задачи.

## Разработка

Принципы развития самой ViaFerrata и правила работы в её репозитории описаны в [AGENTS.md в репозитории](https://github.com/ArtMan-8/ViaFerrata/blob/trunk/AGENTS.md).

```sh
npm ci
node bin/vf.ts --help
npm run lint
npm run format:check
npm run typecheck
npm run test:all
npm run build
```

`npm test` запускает локальные тесты; `npm run test:package` проверяет установку и работу пакета и требует доступа к npm registry. `npm run test:all` выполняет оба набора. `npm pack` собирает JavaScript и создаёт архив пакета.
