# ViaFerrata

Инструмент для разработки с ИИ-агентами: процесс, гейты и артефакты — ADR, спецификации задач, журналы — живут в репозитории проекта.

Ранняя разработка, опубликованных версий нет. Документы — по-русски; заголовки разделов — канонические английские.

## Requirements

Node.js `>= 24.22.2`.

## Usage

Запуск из клона репозитория:

```sh
node bin/vf.mjs --version
```
